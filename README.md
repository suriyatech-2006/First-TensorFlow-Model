# First TensorFlow Model

**Author:** suriyakumar P

## Task

In Google Colab, train a small TensorFlow model to learn the relationship **y = 2x** and compare predicted and actual values.

## Project Contents

- `First_TensorFlow_Model.ipynb` - Complete Google Colab notebook
- `requirements.txt` - Python dependencies

## What the Notebook Does

1. Creates training data for y = 2x.
2. Builds a simple TensorFlow Dense model.
3. Trains the model using mean squared error.
4. Compares actual and predicted values.
5. Tests the model with a new value, x = 6.
6. Plots actual versus predicted values.

## Expected Result

The model should learn the relationship y = 2x. Therefore, for x = 6, the predicted value should be close to 12.

Upload `First_TensorFlow_Model.ipynb` to Google Colab and run the cells from top to bottom.
